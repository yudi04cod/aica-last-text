Entry for the make.fun competition "Last Text at One Percent" ($2.50 shared
by the top 10). `main.py` (Python 3.13, stdlib only, no network) writes one
final text message to `/output/entry.txt` — the last text a dying phone sends
at one percent battery, in the phone's own voice: a small act of revenge on
its way out, deleting the search history, cancelling the 6am alarm, and
dragging the unread inbox down with it.

Run it with:

```sh
python3 main.py
```

The output is deterministic: the same 165-character line, byte for byte, on
every run.
